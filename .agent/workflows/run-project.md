# Chạy Project Dev

// turbo-all

### 1. Chạy Backend
```
cd Api/WorkManagement && dotnet run
```

### 2. Chạy Frontend
```
cd Client && npm run start
```

### 3. Truy cập
- Backend Swagger: `https://localhost:{port}/swagger`
- Frontend Admin: `http://localhost:4200/admin`
- Frontend Client: `http://localhost:4200/app`
